Alur PR ke SAP
  1. Lengkapi barang, qty & harga di bawah, lalu Simpan.
  2. Barang dikelompokkan per kategori (kolom Kelompok) — satu kelompok = satu PR di SAP. Ubah kelompok bila perlu.
  3. Export Excel per kelompok di tabel "PR SAP per kelompok" — file itu yang di-attach saat membuat PR di SAP.
  4. Setelah SAP memberi nomor, upload kembali file di halaman Progress PR. Nomor tiap kelompok dan status Diajukan terisi otomatis. Kolom di bawah tetap dapat dipakai untuk koreksi manual.
  5. Saat barang datang, isi qty per barang dan nomor GRN pada bagian Monitoring barang datang.
