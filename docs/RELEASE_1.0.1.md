# flowStok 1.0.1 — Stable

Pembaruan identitas dan kenyamanan antarmuka untuk aplikasi gudang.

## Perubahan

- Nama aplikasi berubah menjadi **flowStok** pada launcher Android, header,
  halaman web, pusat unduh, dan dokumentasi.
- Warna antarmuka diperbarui ke biru navy dan sky blue sesuai logo resmi.
- Header, kartu ringkasan, tombol utama, dialog, input, dan navigasi bawah dibuat
  lebih jelas serta nyaman digunakan pada HP dan tablet.
- Logo resmi digunakan pada launcher, aplikasi mobile, web, dan pusat unduh.
- ID paket Android dan database lokal tidak berubah sehingga pembaruan tetap
  mempertahankan akun, cache sinkron, serta antrean offline.

## Kompatibilitas pembaruan

Unggah dua aset berikut pada GitHub Release `v1.0.1`:

1. `flowStok-1.0.1.apk` — nama utama untuk instalasi dan halaman unduh web.
2. `MonitoringStok-1.0.1.apk` — salinan kompatibilitas agar aplikasi 1.0.0 dapat
   menemukan pembaruan otomatis.

Kedua berkas berisi APK dan tanda tangan yang sama. Setelah seluruh perangkat
berada di flowStok 1.0.1, rilis berikutnya cukup memakai nama flowStok.
